# cs5105n-EnriqueRodriguez-SkyGlide

CS-5105N Game Development Portfolio
Game Project Overview
Game Title: SkyGlide

Genre: Endless Runner / Arcade

Developer: Enrique Ray Rodriguez

Short Description: A 2D arcade game inspired by the classic Flappy Bird. The player controls a bird attempting to fly between sets of vertical pipes without hitting them, utilizing physics-based jump mechanics and continuous horizontal scrolling.

# Week 1
The primary goal for Week 1 was to establish a clean, production-ready development workflow using Godot Engine and Git version control. This week focused on setting up the initial 2D scene hierarchy and managing large media assets cleanly in remote storage.
